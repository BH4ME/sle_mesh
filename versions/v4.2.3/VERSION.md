# Version v4.2.3

版本定位：

- 在 `v4.2.2` 基线上，按原理图重新固化 `显示(ST7789) / 蜂鸣器 / WS 灯 / GPS` 四项硬件映射。
- 按你的要求，下载电路相关逻辑不改动（你当前未焊接下载电路）。

本版完成：

1. 显示（ST7789）映射保持并锁定：
- `SCLK=IO6`
- `CS=IO7`
- `MOSI/SDA=IO8`
- `DC/RS=IO9`
- `RESET=IO13`

2. 蜂鸣器映射锁定：
- `BUZZ=IO14`

3. WS 灯映射锁定：
- `RGB/WS2812 DIN=IO0`

4. GPS 映射进入配置和日志：
- `UART_BUS=1`
- `TX=IO17`
- `RX=IO18`
- 启动时会输出 GPS 映射诊断日志，便于现场核对接线；
- 当前仍默认不启用 GPS NMEA 解析（仅完成引脚映射落档与可观测性）。
