# Version v2.0.0-alpha17

版本定位：

- V2 第十七次增量（alpha）：修复域名 WebUI 在板端 SLE 发送繁忙时偶发卡住、需要手动刷新才能恢复的问题。

本版完成：

1. WiFi HTTP 请求容错：
- 域名 WebUI 的 HTTP 请求新增超时控制；
- 单次 `/api/*` 请求卡住时会自动 abort，并释放刷新状态；
- 下一轮轮询可以继续恢复，不再长期停在 busy 状态。

2. 轻量板端 HTTP 压力降低：
- WiFi 刷新从并发请求改为顺序请求；
- 避免同时打 `/api/status`、`/api/nodes`、`/api/events` 给 WS63 轻量单连接 HTTP 服务造成瞬时压力。

3. 自动恢复体验：
- 请求失败时保留已有状态数据；
- 后续自动轮询成功后自动清除错误，不需要手动刷新页面。
