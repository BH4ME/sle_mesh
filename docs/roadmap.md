# 开发路线

## 第 1 阶段：跑通链路

目标：

- 从官方 `SLE` 透传示例起步
- 先把控制命令和自定义协议跑通

输出：

- 可发现设备
- 可入组
- 可发 `PTT_START/PTT_STOP`

## 第 2 阶段：1 对 1 语音

目标：

- 接入麦克风
- 编码并发送 `VOICE_DATA`
- 接收端解码播放

验收建议：

- 室内 3 到 10 米稳定
- 语音可懂
- 连续讲话 3 分钟不死机

## 第 3 阶段：1 对多

目标：

- 扩到 `1 -> 4`
- 再扩到 `1 -> 8`

重点观测：

- 实测时延
- 连续丢包
- 不同距离下可懂度
- 电流和发热

## 第 4 阶段：产品化

补这些能力：

- 配对记忆
- 自动重连
- 低电提醒
- 信道或组号配置
- 音量管理
- OTA 升级

## 现在最值得先做的事

如果你准备马上开工，我建议下一步就做下面其中一个：

1. 直接把 `fbb_ws63` 官方 SDK 拉下来，建立一个基于 `23_sle_uart` 的应用工程。
2. 先把硬件框图定下来，我帮你把麦克风、功放、按键、电源这一层画成文字版 BOM/连接表。
3. 如果你已经买了开发板，我可以按你的板型继续细化具体引脚和软件模块。
